## 📖 Sobre o Projeto

Este projeto foi desenvolvido durante a formação de Node.js da DIO com o objetivo de praticar conceitos fundamentais do ecossistema Node.js, utilizando bibliotecas NPM para gerar QR Codes diretamente pelo terminal.

A aplicação permite transformar textos, URLs ou qualquer informação em QR Code de forma simples e rápida.

---

## 🎯 Objetivos do Projeto

- Praticar JavaScript moderno
- Trabalhar com Node.js no terminal
- Utilizar bibliotecas externas via NPM
- Organizar estrutura de projeto backend
- Criar um projeto para portfólio no GitHub
